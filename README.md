# Crimes and Incarceration Analysis

## Project Overview

This project examines the relationship between crime trends and incarceration across U.S. states. The goal is to determine whether crime and incarceration characteristics can be used to classify changes in violent crime into three categories.

Rather than predicting a simple yes/no outcome, the project uses a multiclass classification approach to categorize violent crime trends as:

* **Decreasing**
* **Stable**
* **Increasing**

The analysis combines crime and incarceration data to explore whether factors such as incarceration levels, prison populations, and reported crime rates can help distinguish between these violent crime trend categories.

## Research Question

**Can crime and incarceration characteristics be used to classify violent crime trends as decreasing, stable, or increasing?**

## Data

The project uses multiple datasets containing state-level crime and incarceration information, including:

* `crime_and_incarceration_by_state.csv`
* `prison_custody_by_state.csv`
* `ucr_by_state.csv`

These datasets provide information on reported crimes, incarceration, prison custody, state, year, and other criminal justice measures.

## Project Objectives

The main objectives of this project are to:

1. Clean and combine crime and incarceration datasets.
2. Explore patterns and trends in violent crime across states and years.
3. Create a three-category violent crime trend outcome.
4. Identify variables that may help classify violent crime trends.
5. Build and evaluate a multiclass classification model.
6. Interpret the results and identify limitations of the analysis.

## Methods

The project will include:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Feature selection
* Multiclass classification
* Model evaluation using appropriate classification metrics

## Tools

This project is being completed using Python and common data science libraries, including:

* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Purpose

The purpose of this project is not to establish that incarceration causes changes in crime. Instead, the analysis focuses on identifying patterns in historical state-level data and determining whether available crime and incarceration characteristics can help classify violent crime trends.
